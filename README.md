# TagAll

Пинг участников. Состав группы подтягивается пользовательским аккаунтом.

## Синхронизация через аккаунт

Обычный бот не видит весь состав. Нужен отдельный аккаунт в этой же группе (лучше админ).

1. Открой https://my.telegram.org → *API development tools* → создай приложение.
2. Скопируй `.env.example` в `.env` и заполни:

```
BOT_TOKEN=токен_бота
API_ID=123456
API_HASH=xxxxxxxx
PHONE=+79991234567
SYNC_EVERY_MINUTES=180
```

3. Один раз войди в аккаунт (код придёт в Telegram):

```bash
python login.py
```

Появится `data/user.session`. Этот файл и есть авторизация — его нельзя светить.

4. Запусти бота и в группе (от админа):

```
/sync
```

Дальше состав обновляется сам раз в `SYNC_EVERY_MINUTES` минут. `0` — выключить автосинк.

Аккаунт должен быть **участником** группы. В больших супергруппах полный список часто отдают только админу.

Не логинь основной номер. Telegram может дать FloodWait или ограничить аккаунт, если синкать огромные чаты часто.

## Команды

| Команда | Действие |
|---|---|
| `/all [текст]` | пинг всех из базы |
| `/sync` | подтянуть состав аккаунтом (админ) |
| `/out` | не пинговать 1 час |
| `/out 30m` `/out 2h` | другая пауза |
| `/in` | вернуть пинги сразу |
| `/stats` | база и дата последнего синка |

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python login.py
python bot.py
```

BotFather: `/setprivacy` → Disable. Бота в группу админом.
